# LASU Alumni WordPress Theme

A minimalist, lightweight WordPress theme for the **Lagos State University (LASU) Alumni Association**.

## Features

- Matches LASU logo color scheme: Gold (#FCBF29), Blue (#0089E2), Dark (#24211C), Orange accents
- Fast-loading: system fonts, minimal CSS, no heavy frameworks or page builders
- Homepage with six+ sections: Hero, What We Offer, Latest News (dynamic), Upcoming Events, Membership Benefits, Alumni Spotlight, Get Involved
- Best practices for alumni association sites
- Fully responsive
- Supports custom logo, primary menu, featured images, and standard WordPress features
- GPL licensed

## Installation

1. Download or clone this repository.
2. Zip the theme folder or upload via WordPress admin.
3. Activate the theme.
4. Set a custom logo, create a Primary Menu, and add pages for Membership, Events, About, Contact, etc.
5. Publish posts to populate the Latest News section.

## Recommended Pages

- Home
- About the Association
- Membership / Join
- Events
- News
- Contact
- Give / Donate

## Customization

Colors are CSS variables in `style.css`. Homepage sections are in `index.php`.
