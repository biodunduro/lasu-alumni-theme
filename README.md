# LASU Alumni WordPress Theme

A minimalist, lightweight WordPress theme for the **Lagos State University (LASU) Alumni Association**.

## Features

- Matches LASU logo color scheme: Gold (#FCBF29), Blue (#0089E2), Dark (#24211C), Orange accents
- Fast-loading: system fonts, minimal CSS, no heavy frameworks or page builders
- Best practices for alumni association sites:
  - Hero section for engagement
  - Sections for networking, events, giving back
  - Clean news/blog display
  - Easy membership and event promotion
- Fully responsive
- Supports custom logo, primary menu, featured images, and standard WordPress features
- GPL licensed

## Installation

1. Download or clone this repository.
2. Zip the `lasu-alumni-theme` folder (or upload the contents as a theme folder).
3. In WordPress admin: Appearance → Themes → Add New → Upload Theme.
4. Activate the theme.
5. Set a custom logo (Appearance → Customize), create a Primary Menu, and add pages for Membership, Events, About, Contact, etc.
6. Optionally create a static homepage or use the blog as the front page.

## Recommended Pages

- Home (with hero)
- About the Association
- Membership / Join
- Events
- News
- Contact
- Give / Donate (link to external if needed)

## Customization

Colors are defined as CSS variables in `style.css`. Edit there for fine-tuning.
